# Agent Note: 漫剧独立分类与视频播放复用

Status: implemented

## Problem

用户需要从首页找到并观看漫剧。现有客户端只有小说、短剧、漫画和听书分类，漫剧视频可能显示为短剧，也可能混入按搜索关键词归组的漫画栏目。历史记录无法表明作品是漫剧。

2026-09-09 的接口实测确认独立漫剧首页与完整剧集、播放源均可访问，但首页不提供下一页游标；搜索中也没有独立漫剧 tab。

## Decision

`MediaItem.kind` 增加 `manju`，首页、搜索、详情、书架与统计显示“漫剧”。`isVideoKind` 将 `video` 和 `manju` 路由到已有 `PlayerPage`，详情、目录与播放请求仍使用后端接受的 `tab=短剧`。两类内容共享 Media3 与 CENC 解密，不需要修改 Go 或原生播放器。

漫剧首页请求 `tab_type=24`，只解析匹配栏目的内容、会话和游标。这个来源可以为没有漫剧标签的卡片指定类型。普通搜索只接受 `genre=205`、结构化漫剧标签或显式类型作为证据，标题、简介和作者名称不参与判定；综合结果保留漫剧，其他类型的结果中移除漫剧，独立“漫剧”tab 去重展示。

搜索页按用户要求固定显示综合、短剧、漫剧、漫画、听书，顺序不受上游 tab 排列或空结果影响，综合中保留小说。各分类的请求来源、类型过滤与分页隔离由[搜索分类修复](../bug-fix/2026-09-10-search-categories.md)接管；这里保留漫剧识别、首页和播放复用的决定。

推荐游标耗尽后，首页调用 `query=漫剧&tab_type=11` 的视频搜索。`SearchTab` 保留 `hasMore` 与 `nextOffset`，漫剧分页使用真实偏移量，空页或重复页只要游标前进就继续。综合首页为该来源单独保存偏移量与耗尽状态，请求失败不推进偏移量，刷新重置状态。

视频历史继续用原系列 ID 作为存储键。旧 `video` 记录可在漫剧详情中续播，播放后保存为 `manju`；已保存的 `manju` 通过普通视频入口打开时也不降级。这样可以沿用原来的集数、秒数与累计观看时间，不需要迁移或复制历史。

## Alternatives considered

- **仅加首页入口，所有漫剧仍存为 `video`**：改动小，天然复用全部播放逻辑。但搜索过滤与历史类型无法区分漫剧，用户从不同入口打开同一作品时仍会看到短剧标签，因此采用独立内容类型。
- **新建漫剧播放器与历史命名空间**：便于将来增加专属播放行为，也能完全隔离存储。目前已验证的目录与播放源和短剧相同；复制播放器会重复维护切集、预取、解密和状态竞争，换历史键还需要迁移旧进度，因此保留一个播放器和既有历史键。
- **按标题关键词识别并递增推荐偏移量**：能够用很少状态填充列表，但会把同名原著或出版社命中当作漫剧，并反复请求没有游标的推荐页。采用结构化类型证据与接口返回的搜索游标。

## Consequences

漫剧具备独立浏览和续看体验，同时沿用已有播放能力。代价是首页需要维护一个额外搜索来源的游标、失败重试位置与耗尽状态，类型展示的映射也需要覆盖 `manju`。

搜索回退受“漫剧”关键词与上游返回标签限制，不保证覆盖完整片库；缺少标签的搜索结果不自动归为漫剧。若上游提供独立漫剧搜索或有效推荐游标，应优先接入该来源并保留现有历史身份。分类编号属于不同 API，不可把首页 `24`、视频搜索 `11` 与漫画搜索 `8` 混用。

## Verification

- `test/manju_api_test.dart` 使用裁剪后的真实响应结构覆盖来源分类、标签识别、误判排除、系列/单集字符串 ID、搜索分组和跨栏目游标隔离。
- `test/home_provider_test.dart` 覆盖 `0 → 17 → 23` 偏移量、重复/空页、失败重试、耗尽与刷新；首页组件测试同时检查插入分类后的漫画和听书入口。
- 详情与播放器测试覆盖旧 `video` 记录续播、`manju` 不降级、原系列 ID 和秒数保留；历史与书架测试覆盖观看时间类型及集数单位。
- 执行 `flutter analyze --no-pub`、`flutter test --no-pub --concurrency=2` 和 ARM64 release 构建。实际结果与 APK 校验见 [漫剧接入验证](../../../../docs/manju-validation-20260910.md)。
- 接口验证包含目录、播放源和 CDN MP4 分段读取。此次没有进行 Android 真机解码播放，自动化播放器测试使用可控替身。
