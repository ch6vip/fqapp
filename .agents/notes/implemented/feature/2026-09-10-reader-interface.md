# Agent Note: 阅读菜单分层与设备设置隔离

Status: implemented

## Problem

用户要求参考本地 Legado 的阅读界面，确认先完成菜单、阅读信息、排版和亮度。旧页面通过增删 Scaffold 的 AppBar 和 bottomNavigationBar 开关菜单，正文可用高度随之改变。排版只有基础滑块，目录采用应用配色，夜间阅读时可能弹出日间面板；页面没有独立亮度与字体导入。

## Decision

[阅读页](../../../../lib/pages/reader_page.dart) 用固定正文区域加两个 Positioned 覆盖层显示菜单。动画、点击关闭和返回键只改变菜单，不重新分配正文空间。阅读信息单独显示书名、章节、进度、时间、电量，支持关闭。章节缓存和历史继续复用原接口；排版变化时的位置恢复由 [分页与文字位置决定](2026-09-10-reader-pagination.md) 接替原段落比例方案。

[排版面板](../../../../lib/widgets/reader/reader_appearance_sheet.dart) 将常用参数分成紧凑卡片，标题和留白放在展开项内，小屏或大字体使用单列。正文、菜单、目录、缓存使用同一阅读配色。字体、颜色与几何配置沿用 SharedPreferences，旧字段保留，旧标题大小按原字号加二迁移。偏好只在修改后保存，完整快照按顺序写入；队列完成后清空，避免保留已完成异步上下文。

[设备桥接](../../../../lib/services/reader_device.dart) 使用独立 FlutterPlugin。亮度只修改 Activity 的 window.attributes.screenBrightness，跟随系统用 -1；不写系统全局设置。会话标识隔离旧页面的延迟更新和清理，暂停、退出、Activity 分离都恢复原亮度，重建后保存新窗口的原值。系统时间与电量广播在订阅期间更新页脚，不添加 Dart 周期计时器。

字体通过系统文件选择器获取，后台复制到应用私有目录，以内容 SHA-256 命名，校验文件头并限制为 32 MB；Flutter FontLoader 按路径复用已加载字体。取消或导入失败保留原排版，已保存字体不可读时使用系统字体。页面等待排版和字体加载完成后再恢复章节位置。

## Alternatives considered

- 继续使用 Scaffold 的顶栏和底栏：复用系统布局、改动少，但显隐仍会改变正文高度，无法满足菜单不推动正文的要求。
- 直接移植 Legado 的 Kotlin 自绘分页：能复用完整翻页体系，但当前正文、缓存和交互由 Flutter 实现。菜单采用 Flutter 覆盖层，分页在正文侧独立实现。
- 引入亮度、电量和文件选择三个通用插件：跨平台支持更多，但本项目主要交付 Android，现有工程已有原生插件注册机制；小型桥接能明确处理窗口所有权和恢复时机。
- 内置一组中文字体：首次打开即可切换，但字体会随每次 APK 发布增加体积，选择也固定。本轮使用系统字体加用户导入，增加了文件选择和字体失败处理的维护成本。

## Verification

[界面测试](../../../../test/reader_interface_test.dart) 验证菜单动画中的正文位置、返回行为、状态广播、亮度生命周期、排版保存和段落保持、夜间目录、小屏大字体及横屏。设备通道和偏好另有单元测试。Android 的 ReaderBrightnessSessionTest 验证原值恢复、过期清理隔离、后台暂停及 Activity 重建。

Flutter 全量 514 项、Android 单元测试 41 项通过，静态分析和 Lint 通过。`1.0.13 (14)` 已通过 ADB 覆盖安装并启动，用户于 2026-09-10 反馈“测试了没问题”。详细结果、组件预览和安装信息见 [验证记录](../../../../docs/reader-interface-validation-20260910.md)。

## Consequences

菜单开关不再影响正文可用高度，阅读主题覆盖各个面板，亮度作用范围由窗口和会话限定。新增的原生桥接需要随 Activity 生命周期维护，导入字体占用私有存储与字体缓存。

菜单与设备设置保持独立于阅读方式；[分页改动](2026-09-10-reader-pagination.md) 提供真实章节页码与文字位置，同时保留纵向滚动和旧历史兼容。全书百分比仍按章节与章内位置估算。仿真卷页、音量键翻页、书签与朗读不属于菜单和排版改动。
