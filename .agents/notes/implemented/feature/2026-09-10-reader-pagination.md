# Agent Note: 按完整文本行分页与文字位置续读

Status: implemented

## Problem

用户确认在阅读菜单和排版基础上继续实现左右分页、跨章翻页与真实章节页码。旧历史只有滚动像素和滚动范围，字号、字体或窗口改变后，按比例恢复会落到不同的正文；仅滚动一屏也无法提供实际页数。已有离线缓存、目录、阅读时长和历史保存顺序需要继续有效。

## Decision

[ReaderChapterLayout](../../../../lib/widgets/reader/reader_chapter_layout.dart) 使用 Flutter TextPainter 测量标题与每个完整段落，生成文本行、字符范围和页面片段。分页与滚动共用同一份 TextSpan、字体缩放、缩进、两端对齐和行高参数。分页片段裁切原段落的完整行，保留原始排版；段落跨页时不会重新缩进或因再次两端对齐改变换行。只有当前章节保留测量结果，菜单、时钟和亮度更新不重新分页。

行边界通过逻辑文字偏移依次读取。按屏幕坐标命中行内字符在混合 emoji 和 RTL 字形时可能命中其他行，导致范围倒退；逻辑行边界避免这个问题。后备字体把同一字素分到多行时，这几行作为一个不可拆分单元；只有缩进而没有正文的行也与后续正文合并。极小窗口容纳不下一行或一个字素单元时，该页允许纵向滚动，不裁掉正文。空标题不生成空白页。

[ReaderPagedView](../../../../lib/widgets/reader/reader_paged_view.dart) 用 PageView 承担左右拖动和点击动画，在当前章两侧设置换章入口；下一章从首页开始，上一章从末页开始。翻页动画期间不叠加点击请求，章节请求沿用原有去重和预取。加载失败不覆盖最后显示的历史，重试保留从上一章末页进入的意图。菜单打开时收起边界提示，避免提示遮住目录按钮。

[阅读页](../../../../lib/pages/reader_page.dart) 保存 `positionVersion: 2` 和 `textOffset`。偏移以 UTF-16 计数，对应“章节标题、换行、图文块”的顺序；空标题省略，每张插图以一个 U+FFFC 对象占位字符计数，块间保留一个换行。章节仍按 ID 识别。排版变化时保留原偏移并定位到包含它的新页面，不把每次重新分页后的页首再当作新的锚点，避免反复调字号造成进度向前漂移。只有用户翻页或滚动才更新锚点。

插图按已知比例预留高度，最大为一页，作为不可拆分块参与两种模式的布局。空标题不产生段间距。`positionVersion: 1` 的旧文字偏移利用保留的旧规范化正文映射到新图文块，连续图片获得不同偏移。图文来源、缓存升级与首次布局竞争处理见 [小说插图决定](../bug-fix/2026-09-10-reader-illustrations.md)。

旧历史首次读取时，根据 `position / maxScroll` 换算当前布局中的位置，再保存文字偏移；没有有效范围时兼容原像素位置。`position`、`maxScroll`、章节序号、封面等字段继续写入，兼容旧版本和书架。滚动列表提供精确条目高度，使较远的文字位置无需依赖懒加载列表的高度估计。新布局显示且位置恢复后才允许保存历史，原 ReaderHistory 写队列继续防止退出和重开时旧记录覆盖新进度。

[阅读偏好](../../../../lib/services/reader_preferences.dart) 默认使用左右分页，排版面板可选择上下滚动并持久保存。页脚显示当前章真实页数；全书百分比仍根据章节和章内位置估算。菜单、主题、设备亮度和字体导入沿用 [阅读界面决定](2026-09-10-reader-interface.md)，其中段落比例定位由本篇的文字偏移方案接替。

## Alternatives considered

- 将正文切成每页字符串后用普通 Text 重新布局：页面组件简单，也容易独立处理选字，但段落续页的首行缩进、两端对齐和混合字形可能再次改变断行。本实现保留原段落排版，页面只引用其中完整的行。
- 直接移植 Legado 原生分页引擎：已有成熟的阅读和翻页能力，但正文、缓存与页面生命周期目前都在 Flutter 中；增加原生绘制面与两套状态同步会扩大本轮范围。这里使用 Flutter 自身的排版结果与 PageView。
- 先渲染全部段落，再从 RenderParagraph 收集位置：测量与显示天然一致，但需要把长章节全部建成组件，或者接受懒加载时页数不断变化。预先测量当前章、按需构建可见段落能提供确定的页数和位置。

## Verification

[行排版测试](../../../../test/reader_chapter_layout_test.dart) 检查不同窗口和字体缩放下文字完整、字素不拆页、片段不重叠、测量与真实渲染一致、远处滚动位置、空标题、旧历史与损坏数据兼容，以及小于一行的窗口。

[分页交互测试](../../../../test/reader_pagination_test.dart) 检查点击和滑动、快速连续点击、菜单不改分页、双向跨章、失败重试、横竖屏与重复字号修改、切换阅读方式、延迟保存后重开、旧记录迁移和章节边界。原阅读界面测试明确使用滚动模式，继续检查既有菜单、亮度与排版行为。发布结果和组件预览见 [验证记录](../../../../docs/reader-pagination-validation-20260910.md)。

Flutter 全量 538 项与静态分析通过；Android Lint 为 0 项错误、6 项已有警告。`1.0.14 (15)` 的 ARM64 release APK 通过签名和 16 KiB 对齐校验，并经 ADB 覆盖安装与启动，启动进程检查未发现崩溃。

## Consequences

当前章页数有实际布局依据，文字偏移可以跨阅读方式与排版配置恢复，也为以后书签和选字提供位置基础。代价是打开章节或更改排版时需要测量整章，页面片段还需维护原段落坐标和可访问性文字；邻章继续只预取正文，进入后再按当前窗口分页。很长的章节或很大的导入字体可能增加重新排版耗时。

旧像素记录只能首次近似迁移；上游修改正文后，原偏移也可能指向变化后的文字。本轮提供水平滑动动画，仿真卷页、音量键、书签、长按选字和朗读仍为独立后续能力。
