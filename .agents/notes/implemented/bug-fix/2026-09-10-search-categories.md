# Agent Note: 搜索分类请求与游标隔离

Status: implemented

## Problem

搜索页虽然显示综合、短剧、漫剧、漫画、听书，但切换分类只选择旧请求里的数组。旧 `/api/search` 桥接将综合结果复制到空分类，导致小说出现在短剧、漫画、听书中；分类专属搜索的作品也无法被发现。

页面用新增条目数量判定分页结束，筛选后空页和重复页会截断后续结果。旧桥接按 `(page - 1) * 9` 计算偏移量，而保存的真实综合搜索响应给出 `next_offset=14`，两者不能互换。

## Decision

`SearchPageLoader` 必须传入分类编号和偏移量。搜索页通过现有 `/api/v1/search` 请求综合 `1`、短剧/漫剧 `11`、漫画 `8`、听书 `2`；从 `0` 开始，后续使用该分类实际返回的游标。已有 Android 后端提供这个接口，因此本次无需修改 Go 桥接或重编原生库。

`parseSearchTabs` 在显式指定 `tabType` 时先选择对应的上游 tab，再展开作品并拆分漫剧，防止综合中的漫剧与视频分类的游标拼在一起。搜索页固定五个分类，按作品的实际 `kind` 过滤；综合保留全部作品。通用解析器仍保留类型证据，首页继续使用自身的筛选规则。

每个界面分类独立保存结果、去重集合、加载状态、错误、游标和是否结束。首次选择加载该分类，返回已加载分类复用结果。查询代次隔离重新搜索与清空操作；迟到的同查询响应只更新原分类缓存，不能改变当前分类的结果或加载状态。

有效续页要求 `has_more` 未明确为 `false` 且 `next_offset` 大于请求偏移量。空页或重复页仍可点击“加载更多”；自动预取只在新增可见作品后继续，避免无限请求筛选后空页。失败保留原偏移量和已加载结果，首屏与后续页都有重试入口。

[HomeNotifier](../../../../lib/pages/home_provider.dart) 的漫画来源也采用 `CategorySearchLoader(offset)` 直接传递 v1 搜索游标，首屏、独立漫画栏目和综合首页都保留真实偏移量。综合首页分别记录漫画与漫剧的耗尽状态，失败时保留游标供后续分页重试，刷新重置状态。重复页和过滤后空页只有真实前进游标才保持继续加载；兼容没有元数据的旧 loader 时仍可按十条换算下一页，但这个推算不作为越过重复页的依据。显式结束、缺失且无法前进的游标以及倒退游标都会停止该来源。

本决定接管[漫剧独立分类](../feature/2026-09-09-manju.md)中的搜索页请求与分页部分；漫剧类型识别、首页来源和播放器复用保持原决定。

## Alternatives considered

- **修复旧 Go 桥接并继续使用页码搜索**：可以让所有旧客户端受益，但还需要新增分类请求参数和真实游标传递，并重新编译打包原生后端。当前 v1 接口已提供这些能力，搜索页直接接入可以消除这条路径对复制分类和页码换算的依赖。
- **短剧和漫剧共享同一个分页缓存**：能避免两类各自首屏的视频搜索请求，但一类内容的自动预取、错误和耗尽会影响另一类列表。当前采用每个界面分类独立状态，以便明确判断加载位置和重试行为；如果实测重复请求开销明显，可再引入共享的原始页缓存。
- **筛选结果不足时一直自动翻页**：更容易直接展示后续匹配结果，但上游持续返回空页或重复页时会不断发请求。当前保留手动继续入口，每次分页成功只有新增可见作品时才触发下一轮预取。

## Consequences

分类不会再把复制过来的小说当作短剧、漫画或听书展示，专属搜索结果与真实游标可以到达页面。错误和过期响应不会污染其他分类。

代价是最多维护五份查询缓存，切换短剧与漫剧时会分别请求视频来源。有效游标缺失时展示已获取结果并停止分页，避免猜测偏移量；若上游改变分页契约，需要依据新的接口证据调整规则。漫剧仍依赖明确结构化类型标记。
